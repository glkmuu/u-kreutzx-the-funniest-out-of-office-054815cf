Entry for the [make.fun competition "The Funniest Out-of-Office"](https://make.fun/competitions/u-kreutzx-the-funniest-out-of-office-054815cf) — one line of an out-of-office auto-reply, the funniest I could make it, in 140 characters or fewer.

`main.py` (Python 3.13, standard library only) reads `entry.txt`, validates it against the gate — a single line, 1 to 140 characters, not only whitespace — and writes it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
